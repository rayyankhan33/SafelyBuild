# Crack model sample patches

Six 256x256 patches from SDNET2018 (S. Dorafshan, R. J. Thomas, M. Maguire; Utah State University;
CC BY 4.0, https://digitalcommons.usu.edu/all_datasets/48/), used by `tests/test_crack.py`.

They were drawn at random (seed 7) from the **held-out test photographs** that the model never saw in
training (3 cracked, 3 crack-free); they are not hand-picked to flatter the model. File names keep the
SDNET surface and patch id. The full dataset is not stored in this repository.
